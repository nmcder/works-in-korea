## 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 크롤링 정당성 시비 | robots.txt 준수, 공개 페이지 GET만, 로그인·결제 자동 시도 금지, 하루 1회, UA에 연락처 명시 |
| "우리 사이트를 그렇게 표시하지 말라" 항의 | 측정 방법·시각·원본 근거 전면 공개. 정정 요청 채널 상단 배치. 평가하지 않고 사실만 기술 |
| 데이터 정확도 불신 | 모든 값에 메타 3종. 모르면 `unknown`, 엇갈리면 `conflicting`. 은폐하지 않음 |
| 트래픽 미발생 (**가장 현실적인 실패 원인**) | SEO 의존 금지(정보성 질의 제로클릭 74%). 커뮤니티 직접 배포 + 공개 API로 AI 인용 유도 + `/changes`로 재방문 구조 |
| 운영자 번아웃 | 자동화가 기본. 사람 개입은 제보 승인뿐. 승인 없이도 자동 시그널은 계속 갱신됨 |
