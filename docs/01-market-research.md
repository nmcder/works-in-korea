이 문서는 "왜 이 아이템인가"의 근거입니다. 방향을 바꾸고 싶어질 때 먼저 읽으세요.

## A. 2026년의 구조적 제약 — 아이디어 선정 기준 자체가 바뀌었다

### A-1. 제로클릭 65~93% → "정보 모아 보여주기" 모델은 사망

| 지표 | 2026년 수치 |
|---|---|
| 구글 제로클릭률 | 64.8% (2019년 50%에서 지속 상승) |
| AI Overview 노출 시 CTR | **-61%** |
| AI Overview 발생 검색 중 무클릭 종료 | 83% |
| Google AI Mode 제로클릭률 | **93%** |
| 정보성 질의 제로클릭률 | 74% (거래성은 31%) |
| 퍼블리셔 구글 유입 | 2025년에 이미 1/3 감소 |

2026년 4월 디렉터리 사이트 11개 감사 결과: **1개만 유기적 성장 중, 2/3가 24개월간 미국 유기 트래픽 21~98% 상실.**

원인 진단(원문): *"공개 데이터는 더 이상 차별화가 아니다. AI 모델이 디렉터리가 크롤링·정규화·재발행하는 것보다 빠르고 정확하게 1차 출처에서 합성한다."*

### A-2. 그래서 살아남는 패턴은 3가지뿐

1. **실시간 데이터** — 다른 데서 못 얻는 "지금 이 순간" 정보
2. **직접 측정한 1차 데이터** — 웹에 존재하지 않아 내가 만들어야 하는 데이터
3. **마찰이 있는 검증 데이터** — 진입장벽 자체가 해자

**즉사 패턴:** 공공데이터 API 받아서 예쁘게 보여주기, 정책·정보 모아보기, 큐레이션 디렉터리.
→ 흔한 사이드프로젝트 아이디어 대부분이 여기 해당합니다. 주의.

**Works in Korea? 는 3가지를 모두 만족합니다.** 이게 선정 이유입니다.

### A-3. 비상업 제약은 약점이 아니라 구조적 이점

- **Vercel Hobby 무료 티어는 애초에 비상업 프로젝트 전용** (100GB 대역폭, 함수 100만 호출).
  상업화하면 유료 전환 대상 → 현재 조건이 정확히 맞물림.
- **GitHub Actions**: 퍼블릭 무제한 / 프라이빗은 Free 2,000분·Pro 3,000분. 학생팩으로 Pro 무료.
- 선례: **코로나라이브** — 2000년생 학생이 혼자 2년 운영, 누적 조회 1.9억 회, 광고 0원·정부지원 0원.
  남은 후원금 4,136만원 전액 기부. 성공 공식은 "흩어진 데이터의 실시간 집계 + 압도적으로 단순한 UI".

### A-4. 월 10만원의 실제 구매력

인프라(호스팅·크론·엣지·DB)가 전부 0원이므로 **예산 전액을 LLM API에 투입 가능**.
2026년 8월 저가 모델 실가격: Qwen3.7 Flash $0.03/$0.13 per M tokens, DeepSeek V4-Flash $0.14/$0.28, Ling-2.6-flash $0.01/$0.03.
→ 월 5만원이면 수천만~수억 토큰. "AI가 반복 노동을 대신하는" 설계가 예산 안에서 성립.

### A-5. 법적 제약 (반드시 준수)

- **개인정보보호법**: 2026-03-10 공포, **2026-09-11 시행**. 유출 인지 후 72시간 내 통지 의무,
  중대·반복 위반 과징금 상한 **전체 매출액의 10%**, 개인정보 보호책임자 미지정 과태료 신설.
  → 회원가입·개인정보 수집을 아예 안 하면 이 리스크가 통째로 사라집니다.
- **세무**: 완전 무료·무광고는 사업자등록 불필요. 단 애드센스·제휴 링크를 붙이는 순간
  반복·정기성이 인정되어 사업소득 → 사업자등록 원칙, 미등록가산세 1%.
  **후원금도 안전하지 않음** — "명칭에 상관없이 종합소득세 신고 대상"이며
  세법상 비영리조직이 아닌 개인은 기부 수령 불가(증여세 대상).

## B. 선정된 시장 — 방한 외국인 디지털 장벽

### B-1. 시장 규모: 역대 최대, 급성장 중

| 기간 | 방한객 | 증감 |
|---|---|---|
| 2026 상반기 | **1,071.0만 명** | **+21.3%** (반기 기준 역대 최대) |
| 2026 1분기 | 475.9만 명 | +23% (1분기 역대 최대) |
| 2026년 3월 단월 | 약 206만 명 | 월별 최대 기록 |
| 2025 연간 | 1,870만 명 | 2019년 최고치(1,750만) 돌파 |

국가별 2026 1분기: 중국 145만(+29%), 일본 94만(+20.2%), 대만 54만(+37.7%).

### B-2. 불만의 성격이 물리적이 아니라 디지털이다

야놀자리서치, Reddit 기반 한·일 비교 구조분석:

| 카테고리 | 한국 | 일본 |
|---|---|---|
| **디지털 서비스** | **27.8%** | — |
| 관광 정보 | 16.4% | 관광 15.9% |
| 교통 | 13.1% | 23.0% |
| 결제 | 12.0% | 식음 12.8% |

상위 4개가 한국 불만의 69.3%.

**세부 마찰 지점** (괄호는 감정 강도):
- 가입·인증 장벽 **13.1%** (0.61)
- 디지털 서비스 오류 10.4% (0.62)
- 결제수단 제한 11.5% (0.44)
- 내비게이션·길찾기 10.3% (0.48)
- 차별적 응대 4.1% — **강도 0.78로 데이터셋 최고치**
- 택시 문제 4.8% (0.53) / 안전 우려 1.9% (0.55)

**보고서 결론(원문 취지):** 한국은 **"디지털 요새(Digital Fortress)"** 로 기능하며, 관광객은 서비스를 경험하기 *전에* 진입 장벽에 부딪힌다. 일본은 혼잡·물리적 복잡성에서 오는 "이용 피로"인 반면 한국은 "진입 차단"이다.

### B-3. 불만 접수가 3년 새 6배

| 연도 | 관광 불만 건수 |
|---|---|
| 2022 | 288 |
| 2023 | 902 |
| 2025 | 1,744 |
| 2026 (5월까지) | 1,217 → 사상 최대 확실시 |

→ **언론 소재로서의 가치**. 홍보 자산으로 활용 가능.

### B-4. 별도 확인된 정성 신호

- 은행 앱이 영어를 지원하지 않음. 외국 이름(전치사·세례명·복성)이 한국식 3음절 입력칸에 안 들어감
- 영화 예매 시 트래블카드 불가 → 한국 카드/계좌 필요 → 결국 극장 방문
- 카카오페이·네이버페이는 단기 방문자에게 사실상 접근 불가. 애플페이는 NFC 단말 보급이 느림
- 국제카드(비자·마스터 포함)가 본인인증·3DS 추가 레이어를 거치며, 영문 이름 한 글자만 달라도 **이유 설명 없이 거절**
- 전문가 제언이 *"휴대폰 본인인증 대신 이메일 기반 인증 허용을 최우선 과제로"* 로 수렴 중

## C. 경쟁 분석 — 공급 측이 비어 있다

### C-1. 가장 근접한 경쟁자: Seoulstart 디렉터리 (직접 확인함)

| 항목 | 현황 |
|---|---|
| 형식 | **수기 작성 블로그 글** (서술형 문단) |
| 커버리지 | 50여 개 |
| 갱신 주기 | 분기 1회 수동 재검증 (최종 2026-06) |
| 속성 데이터 | 영어 지원·해외카드 여부를 **문장 속에 묻어서** 언급 |
| 항목별 측정 시각 | **없음** |
| 기계 조회 | **불가** |

평가 원문 취지: *"사람이 읽기 좋은 큐레이션 자료이지, 데이터베이스로 질의 가능하지 않다."*

기타 경쟁자: KLifeChoice, lacha, Expat Guide Korea, 90DayKorean, mileasia, Klook 블로그 — **전부 블로그 글**.
정부 측: korea.net 웹사이트 디렉터리, gov.kr 외국인 포털 — 정적 링크 목록.

### C-2. 결정적 신호: 기존 정보원들이 서로 모순한다

같은 질문에 출처마다 답이 갈립니다:

| 질문 | 출처 A | 출처 B |
|---|---|---|
| 배달앱 해외번호 가능? | 쿠팡이츠·요기요·배민 **한국번호 필수** | 배민 2026년 2월부터 **영·중·일 전 과정 지원** |
| KTX 예매 해외카드? | **카드 실패 잦음** | tickets.interpark.com 영문 포털은 **해외카드 결제 정상** |
| Kakao T 해외번호? | 해외번호 SMS **수신 가능** | (타 출처는 언급 없음) |

**누구도 정답(ground truth)을 갖고 있지 않습니다.** 전부 각자 한 번 겪은 일화를 일반화했고, 시점 표기가 없어 낡았는지 판별 불가.
→ **이 모순 자체가 제품의 존재 이유입니다.**

### C-3. 변화 속도가 블로그로는 못 따라간다 (2026년에만)

- 2월 — 배민 영·중·일 인터페이스 전 과정 지원 개시
- 5월 — 네이버지도 '외국인 설정' 도입 (업주가 외국인 예약 수락 여부 선택)
- 6/22 — PASS 마이데이터 통합인증 서비스 종료
- 재외국민 인증 개편 — 해외 휴대폰 번호 + 전자여권만으로 본인확인 가능
- 8월 — 고속버스 예매 해외 발급 카드 허용 개시
- 서울 대중교통 해외 신용카드 수용 시작

**분기 1회 갱신 블로그는 틀린 정보를 최대 3개월 방치합니다.**
매일 자동 측정 + 측정 시각 표기가 그 자체로 이기는 지점.

### C-4. 정책 순풍 = 미래 고객

서울시·관광공사가 이미 움직이는 중이고(캐치테이블 협약 등), 전문가 제언이 이메일 인증 허용으로 수렴 중.
→ **이 데이터를 필요로 하는 기관이 존재합니다.** 사업자등록 후 첫 B2B 고객 후보.

## D. 검토했으나 탈락한 아이디어 (재검토 방지용)

| 아이디어 | 탈락 사유 |
|---|---|
| 공공데이터 MCP 서버 | **이미 레드오션.** ceami/opendata-mcp, koomook/data-go-mcp, 서울 공공데이터 MCP 등 다수 존재. MCP 생태계 자체가 2026-07 기준 22,311개 서버로 포화 |
| 청년정책 매칭 | 온통청년(3,000여 정책) + 웰로 존재, 정부가 맞춤추천 직접 추진 중. 게다가 A-2의 즉사 패턴(공개 데이터 재발행) |
| 응급실 실시간 현황 | 공공 앱 이미 존재 + **오정보 시 인명 관련 책임 리스크**. 1인 비영리 운영자가 감당할 영역 아님 |
| 웹 접근성 진단 도구 | 도구는 이미 다수(OpenWAX, K-WAH, KWCAG A11y Inspector). 단, **"국내 상위 1,000개 사이트 상시 자동 진단 랭킹 공개"** 형태는 여전히 공백 → 차선책으로 보류 중 |
| 서비스 장애 실측 모니터 | Downdetector 한국판 존재. 자동 프로빙 방식 차별화는 가능하나 우선순위 밀림 |
| 한국어 AI 실측 리더보드 | 포트폴리오 가치는 최상이나 벤치마크 방법론 신뢰성 공격에 취약. 보류 |

**보류 아이디어 중 재부상 1순위: 웹 접근성 전국 상시 랭킹** (공익성·언론 노출 관점에서 강함).
